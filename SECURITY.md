# Política de segurança

Este repositório contém apenas o README do perfil e não tem código executável.

## Como reportar

Para reportar uma vulnerabilidade em qualquer repositório de Macarro10, use
"Report a vulnerability" (Security → Advisories) no repositório afetado ou entre
em contato pelo GitHub ([@Macarro10](https://github.com/Macarro10)). Não abra
issue pública com detalhes.

Inclua, quando souber:

- repositório, commit, tag ou SHA afetado
- descrição do problema e por que é sensível
- passos para reproduzir
- impacto potencial e mitigação sugerida, se houver

Não anexe nem cole segredos, tokens, `.env`, chaves ou dados pessoais.
